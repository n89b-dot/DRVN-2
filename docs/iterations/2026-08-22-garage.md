**Brief.** The garage confirmed ownership and little else: "I already know
which car I own." It lacked utility, personality and emotional payoff.

**Thesis (from `docs/site/brand.md` + `design-system.md`).** *A drawing that
knows what's happening.* Every page is a sheet whose annotations are alive —
values are dimensioned, work arrives as work orders. Provenance (every part
points back at its build) is a supporting fact, never the headline. Voice:
factual, workshop-adjacent, quiet; never fake liveness.

## Pass 2 — Provocateur

Where it was merely competent: the dimensions were static text; the cover
plate was only a photo. Two provocations shipped, both amplifying *the sheet
knows what's happening*:

1. **The sheet draws itself.** Each dimension's spine scales in from the top
   and its ticks follow, staggered left to right as the sheet reveals —
   the same draw-in the horizontal `dimline-h` already performs. Reduced
   motion: drawn at rest.
2. **Ledger stamp on the plate.** When a car has earned money, the plate's
   bottom-right carries `$1,450 OFF IT` in ink, opposite the `SHEET 01`
   stamp. The emotional payoff the brief asked for, stated as a fact and
   earned only by real sales (absent otherwise — never faked).

Considered and not shipped: a second-read easter egg on the plate (odometer
roll on hover) — decoration, not thesis; and a "this car has paid N% of
itself" line — the product doesn't know what the car cost, so it would be
invented.

## Pass 3 — Purist

Read aloud: *a drawing that knows what's happening; provenance supports,
product leads; factual and quiet.*

| Element | Verdict | Outcome |

| Work order "Nothing listed off it — pull a part?" | Question in marketing cadence | "Nothing listed off it yet" |

| Dimension draw-in motion | Same `--t-draw` / `--spring` tokens as every other drawn line | Kept |
| Live red on "Parts live" only when an offer is open | Liveness earned by a real event | Kept |
| Type: sheet name `clamp(22px, 2.2vw, 28px)` sans 600; meta mono 14; dims mono | All from the existing scale; no moonlighting | Cleared |
