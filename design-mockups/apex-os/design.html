SYS/07

Do's and Don'ts

Do

  • One accent (acid) for status, prices, actions; red for one terminal state per screen.
  • Measured values in JetBrains Mono, tabular; headlines/KPIs in Space Grotesk.
  • Build every module as a bordered cell with corner ticks.
  • Encode fitment as verified (platform) vs claimed (seller) — never blur.

Don't

  • Use any border-radius above 0px.
  • Add drop shadows, glows, or decorative gradients.
  • Introduce a second accent, or use red for anything but SOLD.
  • Animate with soft 300ms eases — transitions are stepped, ≤120ms.
